# Grafo de conocimiento

Fuente: https://es.wikipedia.org/wiki/Grafo_de_conocimiento (Wikipedia, CC BY-SA 4.0, descargado 2026-10-21)

Un grafo de conocimiento es un conjunto de objetos llamados vértices o nodos unidos por enlaces llamados aristas o arcos, que permiten representar relaciones de una base de conocimiento usando un modelo de datos en grafo. Se suelen usar para enlazar entidades (objetos reales o abstractos) entre sí mediante propiedades semánticas.​​


== Definiciones ==
No existe una única definición comúnmente aceptada de grafo de conocimiento. La mayoría de las definiciones ven el tema a través de la lente de la  Web Semántica e incluyen estas características:​

Relaciones flexibles entre conocimientos en dominios temáticos: Un grafo de conocimiento (i) define clases y relaciones abstractas de entidades en un esquema, (ii) describe principalmente entidades del mundo real y sus interrelaciones, organizadas en un grafo, (iii) permite interrelacionar potencialmente entidades arbitrarias entre sí, y (iv) abarca varios dominios temáticos.​
Estructura general: Un grafo de entidades, sus tipos semánticos, propiedades y relaciones.​​
Apoyo al razonamiento sobre ontologías inferidas: Un grafo de conocimiento adquiere e integra información en una ontología y aplica un razonador para derivar nuevo conocimiento.​

Sin embargo, hay muchas representaciones de grafos de conocimiento para las que algunas de estas características no son relevantes. Para esos grafos de conocimiento puede ser más útil esta definición más sencilla:

Una estructura digital que representa el conocimiento como conceptos y las relaciones entre ellos (hechos). Un grafo de conocimiento puede incluir una ontología que permita tanto a humanos como a máquinas entender y razonar sobre su contenido.​


== Implementaciones ==
El término se ha utilizado para describir proyectos de conocimiento abierto, como YAGO y Wikidata; federaciones como la nube de datos enlazados abiertos;​ una serie de herramientas comerciales de búsqueda, incluidos el asistente de búsqueda semántica Yahoo Spark, el Knowledge Graph de Google y Satori de Microsoft; así como los grafos de entidades de LinkedIn y Facebook.
En tareas de extracción de conocimiento y procesamiento del lenguaje natural también se utiliza el concepto de relevancia de la entidad (entity salience). La relevancia de una entidad es el grado en que un texto contiene información sobre esa entidad.​
La popularización de los grafos de conocimiento y de las metodologías asociadas ha impulsado el desarrollo de bases de datos en grafo, como Neo4j, GraphDB​ y AgensGraph. Este término también se usa en el contexto de programas para tomar notas que permiten al usuario crear un grafo de conocimiento personal.​
Un grafo de conocimiento representa formalmente la semántica al describir entidades y sus relaciones.​​​ Los grafos de conocimiento pueden usar ontologías como capa de esquema.​​ Gracias a ello permiten realizar razonamientos lógicos para extraer conocimientos implícitos, no solo consultas que requieran conocimientos explícitos.
Para que los grafos de conocimiento puedan usarse en diversas tareas de aprendizaje automático, se han desarrollado varios métodos para obtener representaciones latentes de las características de entidades y relaciones.​ Estas incrustaciones (embeddings) de grafos de conocimiento permiten vincularlos con métodos de aprendizaje automático que requieren vectores de características, como las representaciones vectoriales de palabras. Esto puede complementar otras medidas de similitud conceptual.​
Los modelos para generar incrustaciones útiles de grafos de conocimiento suelen ser un ámbito de aplicación de las redes neuronales de grafos (GNN).​ Las GNN son arquitecturas de aprendizaje profundo que incorporan aristas y nodos, lo que encaja bien con las entidades y relaciones de los grafos de conocimiento. Estas tareas sirven como abstracciones fundamentales para problemas más complejos, como el razonamiento y el alineamiento de grafos de conocimiento.
