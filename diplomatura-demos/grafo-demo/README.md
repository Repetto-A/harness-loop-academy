# Grafo de conocimiento mínimo

`python grafo.py` imprime el grafo en Mermaid (pegalo en https://mermaid.live) y responde consultas por relaciones, como "si se cae api.bcra.gob.ar, qué tools se rompen". Los hechos son tripletas tomadas del código de `mcp-portales-ar`. Salida: `salida-ejemplo.txt`.

Idea para la clase: un RAG busca texto parecido; un grafo sigue relaciones explícitas (dependencias, responsables, impacto).
